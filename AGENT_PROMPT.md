# Prompt for Your AI Coding Agent

I am a beginner learning Java. Help me build this Personal Expense Tracker slowly, one small step at a time.

## Technology
- Java 17
- Spring Boot
- JDBC / JdbcTemplate
- MySQL
- HTML
- CSS
- JavaScript

## Very important instructions
1. Use beginner-level code that is easy to read.
2. Use simple English when explaining code.
3. Do not use advanced Java features.
4. Do not create many classes or folders.
5. Follow the folder structure in `ARCHITECTURE.md`.
6. Keep SQL commands in `ExpenseDAO.java`.
7. Keep request handling in `ExpenseController.java`.
8. Use simple methods and clear variable names.
9. Explain every new file and important line.
10. Do not write the whole project at once.
11. Build only one task from `PHASES.md` at a time.
12. After each task, tell me how to run and test it.
13. Wait for me to confirm that it works before moving to the next task.
14. If an error occurs, help me fix it before adding more code.
15. Do not add login, signup, charts, or extra features in the first version.

## Project features
- Add income.
- Add expenses.
- View all records.
- Edit records.
- Delete records.
- Show total income.
- Show total expenses.
- Show balance.
- Filter by type and date.

## Code style
- Use simple `if`, `else`, loops, and methods.
- Use `BigDecimal` for money.
- Use `LocalDate` for dates.
- Use normal HTML, CSS, and JavaScript.
- Use JavaScript `fetch()` to call Java APIs.
- Add comments when a beginner may not understand the code.

## First task
Do not start coding the full application.

First:
1. Read `README.md`, `PRD.md`, `ARCHITECTURE.md`, and `PHASES.md`.
2. Explain the project in simple words.
3. Help me complete Phase 0 only.
4. Give me the exact installation and checking steps.
5. Wait for my confirmation before starting Phase 1.
